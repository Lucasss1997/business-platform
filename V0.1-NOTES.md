# v0.1 Foundation

## Included

- Shared application shell and neutral working-title branding
- Live Companies list loaded from Supabase
- Search and status filtering
- Company summary metrics
- Create, view, edit and delete company records
- Dashboard populated from company data
- Reusable page header, status badge and company form
- Removed PubTables from the MLT division wording

## Run locally

```bash
npm install
npm run dev
```

## Database expectation

The existing `companies` table is expected to contain the fields already used by the original project:

- id
- company_name
- website
- phone
- industry
- contact_name
- email
- mobile
- division
- status
- lead_source
- annual_value
- notes
- created_at (recommended)

If `created_at` does not exist, remove `.order("created_at", ...)` from `components/DashboardClient.tsx` or add the column in Supabase.

## Next recommended milestone

Move primary contacts into a separate `contacts` table, add authentication, and implement row-level security before wider use.
